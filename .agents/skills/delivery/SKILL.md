# Loomake Delivery

既定の対象は `loomake/loomake` の [マイルストーン1](https://github.com/loomake/loomake/milestone/1)、進行管理は [Issue #121](https://github.com/loomake/loomake/issues/121)。目標日は2026年11月16日。利用者が今回の呼び出しでIssueや段階を指定した場合は、その範囲に絞る。

## 開始時

リポジトリを確認し、適用される `AGENTS.md` と `docs/dev/autonomous-delivery.md` を読む。別リポジトリの作業を始めない。接続済みGitHubツールで対象Issueの最新状態・依存・受入条件を確認し、必要なら認証済みの `gh` を使う。作業状況をスキル内の固定リストから判断しない。

利用者による `$delivery` の明示的な呼び出しは、以下の範囲のGoalを設定して作業を進める依頼として扱う。説明やスキルの作成・編集だけを求められたときはGoalを開始しない。暗黙のスキル選択だけを根拠にGoalを新規作成しない。

## Goalを確認する

利用可能なGoal操作ツールで、現在のGoalを取得する。

- 同じ対象のGoalが有効なら再作成せず、検証結果と最新Issueを照合して続行する。
- 未完了の別のGoalがある場合は上書きせず、対象を確認して終了する。実装やGitHubへの書き込みは始めない。
- 一時停止中、または上限で停止したGoalは勝手に状態変更しない。利用者側の再開操作が必要なら短いコマンドやUI操作を示して終了する。実装やGitHubへの書き込みは始めない。
- Goalがない、または前のGoalが完了しており、利用者がこのスキルを明示的に呼んだ場合は、指定範囲のGoalを作る。利用者が指定していないトークン予算は追加しない。

既定のGoalには次の内容を含める。Issueを指定された場合は、そのIssueの受入条件を完了条件にする。

> Loomakeの2026-11-16初回配布に向け、マイルストーン1とIssue #121で定めた範囲を実装・検証し、各段階の出口、A23の一周、別リポジトリへの導入、必要な配布の受入を証拠で確認する。AGENTS.mdとdocs/dev/autonomous-delivery.mdに従い、依存順に作業し、既存担当と重複しない。仕様ゲート・完了ゲート・要件対応テスト・独立レビュー・必須CIを維持する。確認できる承認範囲でPR・マージ・Issue更新を進め、部分実装で親Issueを完了扱いしない。判断待ちは独立した作業を進め、進められる作業がなければ未決事項と再開条件を報告する。個別承認が必要な公開・リリース等は承認前に実行しない。未実施の受入や公開が残る間は初回配布完了と報告しない。

Goal操作ツールが使えない、またはGoal作成が失敗した場合は、自動継続が有効になったと報告しない。対応するCodexの入力欄で、次の短い指示を送る方法を案内して終了する。この分岐では実装やGitHubへの書き込みは始めない。

```text
/goal .agents/skills/delivery/SKILL.mdに従い、初回配布の完了条件を満たす。
```

## 作業を進める

同じ対象のGoalが有効と確認できた場合、または新規作成に成功した場合に限り、同じ実行で次の着手可能な作業へ進む。担当の重複や未コミット作業は `git worktree list`・既存PR・Issueの記録と照合する。同時3changeの上限にはほかのセッションも含める。作業の選び方と実装・受入・記録の手順は `docs/dev/autonomous-delivery.md` に従う。

Goalの達成はIssueのclose件数や説明だけで判断せず、対象の受入条件と実行結果を確認する。完了前の停止・未実行の検査・承認待ちは明示する。期限や利用上限を超える無期限実行、PC停止後の自動再開は保証しない。
