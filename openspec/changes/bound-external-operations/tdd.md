# TDD実行記録

## 1.1 共通境界

実装前に8件のテストを追加し、未実装モジュールで失敗した。期限・出力超過・共有予算・親の先行終了・SIGINTを実プロセスで検査する。実装後に8件が成功した。上限ちょうどの2MiB出力を最後まで転送する追加検査も成功した。

## 1.2 接続と復旧

準備のGit、push、ghの認証・検索・作成、traceのGit、OpenSpec検証、共有期限での品質コマンドの8件を先に追加し、すべて失敗した。共通境界へ接続すると8件が成功した。PR作成後に応答を失った場合も、再実行で既存PRを確認し、証拠・実装とPRを重複させない。

追加試験では、共有期限がエンジンに届かず約3.2秒待つ失敗と、中断後に別の操作・品質コマンドを開始する2件の失敗を確認した。エンジンへ準備を含む残り時間を渡し、中断状態も共有して修正した。共通境界10件、接続11件が成功した。

既存runner試験では、品質コマンドの時間切れ後にGit checkoutを呼べず、検証用のタスクの完了印が残る失敗を確認した。期待値を維持し、仕様を補足してゲートを再実行した。自分の一時的な変更だけを外部操作なしで元へ戻すように改めた。検証中にtasks.mdが変わった場合は上書きせず止める追加試験も成功した。既存のrun62件も成功した。
