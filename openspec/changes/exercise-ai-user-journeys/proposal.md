# AIによる導入と操作のシナリオ試験

## Why

利用者から、使いやすさはAIで試験するよう指示された。配布物を使い、導入・通常操作・失敗からの復旧の操作結果を再現可能な記録に残す。

## What Changes

- 配布物を独立したプロジェクトへ導入してシナリオを実行する。
- 初回initと再実行、既存ファイルを上書きしない停止を確認する。
- doctor、検証、証拠の記録とレポートを通常の流れで確認する。
- 未回答の質問、テスト対応不足、未コミットの変更から、案内に沿って復旧する。
- 操作・期待した終了コード・実際の終了コードをJSONに記録する。

## Capabilities

### New Capabilities

- `quality-journeys`: AIが作成して実行する、配布物を用いた導入・操作・復旧の試験。

### Modified Capabilities

なし。

## Impact

検査用スクリプトと統合テストを追加する。本体の仕様や利用者の環境を自動で変更しない。実エンジンやGitHub接続、人による利用者試験を実施したとは扱わない。
