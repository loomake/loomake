# add-run-guards

## Why
AI のエンジンに完了ゲートが通るまで直させると、テストを消す、skip にする、設定を緩める、仕様を書き換えるといった直し方で「通して」しまうことがある。run はこうした変更を差分から見つけて止まり、人の承認なしに先へ進まない。出典：run 要件定義書 v0.1 §2、§3.4

## What Changes
- エンジンを動かすたびに、コミットする前の変更を検査する
- テストファイルの削除と、skip・todo の追加を見つけたら止まる（REQ-109）
- loomake.config.json と、lint・型・テストの設定ファイルの変更を見つけたら止まる（REQ-110）
- `openspec/specs/` と trace.md の変更を見つけたら止まる（REQ-111）
- 止まったら差分を表示し、人が承認するまで先へ進まない（REQ-112。承認のしかたは確認待ち）

## Non-goals
- 後のフェーズ：REQ-113（テストの期待値の書き換えの検出）

## Impact
- 影響する capability：run-guards（新規）
- 影響するコード：run のパッケージ
