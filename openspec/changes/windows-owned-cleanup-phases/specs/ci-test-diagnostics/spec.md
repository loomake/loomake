# Spec Delta

## ADDED Requirements

### Requirement: Windows の所有 fixture 停止の区間記録

Windows で所有 fixture を停止する試験は、`LOOMAKE_CI_HEARTBEAT_DIR` があるときだけ、固定のラベルと段階名で、PowerShell の起動から最初の命令まで、最初の命令からの CIM 取得・所有者照合・taskkill の経過、停止全体の時間と元の結果の分類、出力の解析の分類、停止後の待ちと後片付けを記録する SHALL。原点の異なる値を比べず差し引かない MUST。印の形式・重複・順序・単調性の不整合は数値を捨てて不正とし、起動の値が負か期限を超えれば測定不能とし、印の欠落は欠測とする MUST。記録は同期のファイル操作をせず、完了を待たず、例外を外へ出さず、その失敗・遅れは欠測にとどめる MUST。各試験の終わりの行は、それまでの全行の保存が成功したときだけ完全とし、終わりの行がなければ欠測と読む MUST。元の試験の成否・例外・文言・期限・設定と停止の命令の順序を変えてはならず、停止対象の PID・引数・コマンドライン・パス・出力の本文・環境値を記録してはならない MUST NOT。

Source: REQ-363

#### Scenario: 区間の解析
- **WHEN** 停止が成功し、stdout に boot 900・cim 400・owner 410・taskkill 700 の印がある
- **THEN** 4 つの値を記録し、元の結果の分類を ok、解析の分類を ok とし、cim が boot より小さいことを不整合としない

#### Scenario: 停止は成功し印がない
- **WHEN** 終了コードが 0 で、stdout が空か null である
- **THEN** 元の結果の分類を ok、解析の分類を none とし、区間の数値を記録しない

#### Scenario: 期限切れの途中までの出力
- **WHEN** 停止が期限切れになり、stdout が boot と cim の行と、改行のない途中の行で終わる
- **THEN** 元の結果の分類を timeout とし、boot と cim を記録し、途中の行を捨て、渡された結果を変えない

#### Scenario: 印の不整合
- **WHEN** 印が重複する、順序が違う、owner が cim より小さい、cim 以降が負である、形式が違う、または出力が上限を超える
- **THEN** 区間の数値を記録せず、解析の分類を不正とする

#### Scenario: 起動の値の不整合
- **WHEN** boot が負か、期限の 3000ms を超える
- **THEN** boot を記録せず解析の分類を測定不能とし、cim 以降は単調性を満たすときだけ記録する

#### Scenario: 停止のスクリプトの構造
- **WHEN** 停止に使う PowerShell スクリプトを読む
- **THEN** 元の 13 行は元の順序で残り、taskkill の行と終了コードの判定のあいだに行がなく、印はすべて try の中にあり、owner の印は照合の判定のあと、taskkill の印は判定のあとにあり、最後に exit 0 がある

#### Scenario: 保存の失敗と上限
- **WHEN** 記録先がファイルでディレクトリを作れない、一部の行の追記が失敗する、または行が上限を超える
- **THEN** 記録と終わりの呼び出しは例外を投げずに戻り、上限を超えた行は書かず、終わりの行が書ける場合は完全とせず失敗と捨てた行の数を示す

#### Scenario: 保存の固着と中断
- **WHEN** 追記の完了が通知されない、またはプロセスが先に終わる
- **THEN** 記録と終わりの呼び出しは完了を待たずに戻り、後続の行と終わりの行は書かれず、その試験の記録を欠測と読む

#### Scenario: 記録しない環境
- **WHEN** 記録先の指定がない、または Windows 以外で動く
- **THEN** ファイル操作を始めず、停止の結果と例外は記録を渡さないときと同じになる
