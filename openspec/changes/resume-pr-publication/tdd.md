# TDD実行記録

## 1.1 証拠とPRの再試行

PR作成前後の失敗、push失敗、完了後の再実行、実装の追加変更、不正な証拠8種類、検索の失敗や不正な結果8種類の21件を先に追加した。修正前は20件が失敗し、実装変更後の新規証拠記録だけが成功した。

直前の証拠だけのコミットと文書・SHA・合格結果を確認し、安全に再利用する処理を追加した。push後に同じリポジトリと枝のopen PRを確認し、一意に存在すれば新規作成しない。検索の失敗や不正な結果では作成へ進まない。修正後は追加21件と既存のPRテスト7件の計28件が成功した。既存の期待値は変更していない。

ローカルGitのbareリポジトリと代替ghで試験した結果であり、実際のGitHubへ接続して成功したという記録ではない。
