# TDD実行記録

## 1.1 証拠とPRの再試行

PR作成前後の失敗、push失敗、完了後の再実行、実装の追加変更、不正な証拠8種類、検索の失敗や不正な結果8種類の21件を先に追加した。修正前は20件が失敗し、実装変更後の新規証拠記録だけが成功した。

直前の証拠だけのコミットと文書・SHA・合格結果を確認し、安全に再利用する処理を追加した。push後に同じリポジトリと枝のopen PRを確認し、一意に存在すれば新規作成しない。検索の失敗や不正な結果では作成へ進まない。修正後は追加21件と既存のPRテスト7件の計28件が成功した。既存の期待値は変更していない。

ローカルGitのbareリポジトリと代替ghで試験した結果であり、実際のGitHubへ接続して成功したという記録ではない。

## 1.2 再検証と状態保護

今回の検証不合格、HEAD移動、ブランチ切替、作業ファイル変更の4件を追加した。修正前はHEAD・ブランチの2件が失敗した。HEAD移動は未コミット変更として止まったが、検証中の移動として検出していなかった。ブランチ切替はPR作成まで進んでしまった。

品質コマンドの前後のHEADとブランチを比較して、変わった状態を保ったまま停止する処理を追加した。過去の合格は今回の不合格を代用せず、作業ファイルの変更も取り消さない。修正後は追加25件と既存のPR7件・runner62件の計94件が成功した。型検査とlintも成功した。

## 2.1 復旧手順と統合確認

docs/run-recovery.mdに、push失敗・PR作成の失敗・応答不明・検索の失敗・不正な証拠・品質コマンドの状態変更からの確認手順を記載した。文書を含まない旧証拠をレポートで読む互換性と、自動再利用では拒否する条件を分けて説明した。停止メッセージを、既存の証拠コミットを保持した状態にも合う文に更新した後、関連94件が再度成功した。型検査とlintは成功し、changesetを追加した。
