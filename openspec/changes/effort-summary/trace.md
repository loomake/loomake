## 残課題

実装では直さず、Issue に記録する（Issue の作成は管理役が gh の復旧後に行う）。

- 判断要求・試行の回数は、先頭が 0 の `03` も 3 として受け入れる。
- 想定外の例外は `UsageError` に包んで返す。例外の種類は区別しない。
- 表の表示で、前後の空白と幅のない文字を詰めたり残したりする。「（幅なし）」の注記も同じ表示の扱いに含まれる。
- 出典の表示で、パスに含まれる `\` を区別して見せない。
