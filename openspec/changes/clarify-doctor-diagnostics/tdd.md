# TDD実行記録

## 1.1 コマンド分類

npm・pnpm・Yarnの単純なscript呼び出し、直接コマンド、引用付きパス、未対応のシェル構文とWindowsの引用の30件を先に追加し、未実装モジュールによる失敗を確認した。I/Oを持たない分類関数を実装し、30件と型検査が成功した。

## 1.2 診断への接続

欠落script、不正・過大なpackage.json、未対応の構文、Yarnの未確認、引用パス、実行権限、導入パスの種類、共有期限とGit異常の22件を先に追加し、すべて失敗した。実装後は22件が成功した。script本文を実行せず、診断前後でファイルを変えないことも確認した。

既存のCLI試験は成功・失敗の期待値を維持した。健康なfixtureに品質scriptを追加し、node_modules/.binのfixtureへ実行権限を付けて、実際に整った導入を試験する。既存11件を含む33件が成功し、分類の30件と型・lintも成功した。
