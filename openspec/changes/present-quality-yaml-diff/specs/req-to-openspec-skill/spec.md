## ADDED Requirements

### Requirement: 品質 YAML の具体案を分割案と一緒に示す
Skill は、追加 ID と値、既存項目への変更（linked_requirements の追加を含む）の具体差分、またはファイル不在時の新規全文を、既存の分割案と一緒に提示して合意を取るよう定める SHALL。新規ファイルの model も具体的な合意対象に含める。まだ観測できない必須証拠と、CI の完了ゲートが証拠不足になることを案に添える。新しい承認手順は増やさない。

Source: REQ-409

#### Scenario: 具体的な差分を既存の分割合意に含める
- **WHEN** change の分割案を人に示す
- **THEN** 追加 ID・値・既存更新の具体差分、または新規全文と採用モデルを示し、同じ分割合意の中で確認する指示がある

#### Scenario: 証拠不足を案に添える
- **WHEN** 提案する品質基準の必須証拠をまだ観測できない
- **THEN** 観測できない証拠と、CI の完了ゲートで証拠不足になることを案に添える指示がある
