## 3. 隣接した形式とJSON文字列

APIトークンの直後に秘密鍵ブロックがある2件と、JSON文字列の改行・Unicodeエスケープの2件で漏れを再現した。秘密鍵ブロックを先に置換し、文字列の値を復号してから置換するように修正した。閉じる引用符が出力上限で切れた場合も、1件の失敗を再現してから修正した。保存された実際のエンジン出力にも、通常のJSONと上限で切れたJSONの統合試験を追加した。

既存フックを許可する試験では、セットアップ時だけでなくrunによるコミットでもフックが実行されたことを、記録の行数で追加確認する。既存の期待値は維持した。
