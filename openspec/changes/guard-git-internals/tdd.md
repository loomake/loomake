# TDD実行記録

## 1.1 git の設定とフックの変更の検出

エンジンが実行できるフックを足す場合と `core.hooksPath` を設定する場合に、コミットせずに止まることを求めるテストを足した。偽のエンジンにはフックの実行権限を付ける手順（chmod）を足した。現行の実装で 2 件が失敗し、前からあるフックが動く場合の 1 件は成功した。エンジンを呼ぶ前後で、git の設定ファイルとフックのディレクトリの中身を比べて止まるようにして、runner の 200 件が成功した。

## 1.2 置換する秘密情報の形

npm・Slack・GitLab・Google のトークン、JWT、秘密鍵のブロック、Bearer のトークンを置き換えるテストと、診断のストリームでチャンクの境目にある場合のテストを足し、現行の実装で 12 件が失敗することを確かめた（通常の文を置き換えない 1 件は成功した）。形を足し、診断のストリームでは JWT の `.` もトークンの途中として保留するようにして、runner の 213 件が成功した。

security.md のエンジンの変更と診断の行に、git の設定とフックの比較と、置き換える形を足した。changeset を足した。
