## MODIFIED Requirements

### Requirement: 上限のあるファイル読み取り
文書と設定は1ファイル1MiB、同じ文書読み取り処理の合計16MiBを上限とする SHALL。JSONのテストレポートと証拠は1ファイル64MiB、同じ証拠読み取り処理の合計128MiBを上限とする SHALL。trace reportは、使う証拠だけを全部読み、同じ秒の候補は先頭だけを読んで比べるので、証拠の数によらず読み取りの合計は上限に収まる SHALL。共通のreaderは、ファイルの先頭だけを読む操作を持ち、読んだ分を同じ合計に数える SHALL。上限ちょうどは受け付け、UTF-8のバイト数で数える SHALL。最終要素のリンクと通常のファイル以外を拒否し、開いた対象も確認する SHALL。読み取り前のサイズだけでなく実際の読み取り量も制限し、上限を超えた内容を返さない SHALL。使用したファイルハンドルは成功・失敗とも閉じる SHALL。

Source: REQ-171

#### Scenario: 文字数とバイト数が異なる
- **WHEN** マルチバイトの文書がバイト数の上限を超える
- **THEN** 文字数で過小評価せず拒否する

#### Scenario: 複数ファイルの合計が超える
- **WHEN** 各ファイルは上限以内だが合計を超える
- **THEN** 次の読み取りを停止して合計の上限を示す
