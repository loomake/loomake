# TDD実行記録

## 1.1 診断のストリーム処理

現行実装で7件が失敗した。チャンクの全境界、改行のない末尾、保持量を超える単語、通常表示を試験し、ストリームの置換を実装した。単一チャンク内で完結する長い単語もテストで失敗を確認して直し、8件が成功した。試験用の識別文字列だけを使い、実際の秘密情報は使用していない。

## 1.2 転送と表示の境界

現行実装でstderrと質問・進捗の3件が失敗した。エンジンのstderrをストリーム置換へ接続し、runRunのstdoutとprogressを保護した。runner60件、出力予算とstderr5件、ストリーム8件の計73件が成功した。

## 保護の範囲

エンジンのstderr、runnerの質問・停止理由・差分・進捗を、既知のトークン形式について保護する。内部の判定には元のデータを使い、表示と保存の境界で置換する。stderrのチャンク分割は置換の結果に影響させず、末尾も終了時に処理する。4096文字を超えるASCII単語は省略する。

任意のパスワードや個人情報を識別する保証ではない。不要な秘密情報を環境や入力文書へ渡さず、資格情報は必要な用途と範囲に限定する。証拠に保存する仕様の内容は、この診断の置換とは別に機密性を確認する。
