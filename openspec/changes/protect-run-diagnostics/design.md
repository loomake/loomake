# Design

## Context

保存にはmaskSecretsを使う。エンジンのstderrは出力予算を持つpipeになったが、転送内容の置換は行っていない。

## Goals / Non-Goals

診断と表示の既知のトークンを保護する。任意の秘密情報や個人情報の識別、入力文書の機密判定は保証しない。

## Decisions

- ストリームの末尾のASCII単語を保持し、区切りか終了で既存のmaskSecretsへ渡す。これによりトークンの途中でチャンクが切れても置換できる。
- 末尾が4096文字を超える場合は単語全体を省略し、次の区切りまで保持しない。秘密情報かどうかの判定のために無制限の文字列を持たない。
- 終了時に既知のトークンの接頭辞で終わる未確定な単語も保守的に置換する。
- runRunのstdoutとprogressを入口で包み、すべての表示経路に既存の置換を適用する。内部の判定は元のデータで行う。

## Risks / Trade-offs

長い非秘密の単語も省略する。短い通常の診断は維持する。既知の形でないパスワードなどは検出できないため、入力と実行環境へ不要な秘密情報を渡さない運用を文書化する。
