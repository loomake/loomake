# TDD実行記録

## 1.1 所有者と回復の判定

ロックのモジュールがない状態でテストを実行し、失敗を確認した。実装後は6件が成功した。二重取得、解放と再取得、終了済み所有者、不明な所有者、別ホスト、回復処理の競合、所有トークンの交代を確認した。

## 1.2 実行への接続

修正前は二重起動の終了コードが0になり、同秒の実行記録が1件しか残らず、2件のテストが失敗した。ロックと排他的な記録ディレクトリ作成をrunへ接続し、runnerの既存テストを含む68件が成功した。中断後にロックが解放され、再実行できることも確認した。

## 追加の境界確認

別プロセスが所有するロックは生存中に回収されず、そのプロセスを強制終了した後に回復できた。別のGit worktreeでは、元の作業ツリーのロックを保持したまま独立して取得・解放できた。追加後は関連70件が成功した。型検査とlintも成功した。

## 復旧手順

`docs/run-recovery.md`に、終了済みロックの回復条件、手動確認、対象外の共有環境、作業内容と記録の確認を記載した。ロックは未コミット変更の取り消しや、外部操作の重複防止を保証するものではない。
