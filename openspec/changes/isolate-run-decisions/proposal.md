# Why

実行を止める優先順位と完了ゲートの再修正条件が、Git・エンジン・ファイルの操作と同じ関数にある。品質レビューで残ったドメインの規則を、I/Oなしで直接確かめられるようにする。

# What Changes

- エンジンの観測結果と変更検出から停止を選ぶ規則を、読み取り専用の値を受け取る純粋関数へ移す。
- 完了ゲートの観測結果から合格・修正・停止を選ぶ規則を同じ境界へ移す。
- 優先順位が重なるケースと修正回数の境界を直接試験し、既存のrunの統合試験も維持する。

# Capabilities

## New Capabilities
- `run-decision-policy`: 観測済みの実行結果から、停止または次の段階を選ぶ内部の規則。

## Modified Capabilities
なし。現在のrunの表示、終了コード、コミット、公開APIとスキーマを維持する。

# Impact

runnerの内部モジュールと試験、ドメインの境界を説明する文書。実行時依存と公開exportは追加しない。
