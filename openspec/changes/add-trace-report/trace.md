## 仮定

<!-- 承認 欄が空の仮定は verify で警告になる（失敗にはしない） -->

| ID | 関連 | 仮定の内容 | 理由 | 承認 |
|---|---|---|---|---|
| A-05 | REQ-070 | `--change` の change は、進行中の change から探し、なければ archive から探す。「対応する Requirement」は、その change の差分仕様で、その要件を `Source:` に持つ Requirement の名前とする | 検収レポートは、archive したあとに作ることが多い | 承認（2026-10-23） |
| A-06 | REQ-070, REQ-073 | 「最後の検査結果」には、`.loomake/evidence/<change-id>/` の中で記録した日時がいちばん新しい記録を使う。「テスト」は、その記録の verify の結果の、要件ごとのテストファイルの一覧とする | 要件書に、どの記録を使うかの記載がない | 承認（2026-10-23） |
| A-07 | REQ-074 | 初版で `--format html` を指定したときは、HTML は次の版で対応する旨を日本語で表示し、終了コード 2 を返す。`--format` を省いたときは Markdown にする | 要件書は、初版で対応する形式を Markdown と JSON に限っている | 承認（2026-10-23） |
| A-08 | REQ-085 | レポートには、レポートを作った日時を入れない。日時は証拠の記録のものだけを使い、表の行は REQ の番号順に並べる | 作った日時を入れると、同じ入力からでも毎回違うレポートになる | 承認（2026-10-23） |
| A-09 | REQ-087 | TRC-N-05 は HTML のレポートについての要件なので、HTML の出力（TRC-RPT-06）と同じく次のフェーズで扱う | 初版では HTML を出力しない | 承認（2026-10-23） |
