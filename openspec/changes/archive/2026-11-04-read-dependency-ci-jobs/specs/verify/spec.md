## ADDED Requirements

### Requirement: 宣言した CI job の 1 回の内部取得
kit の内部取得はCI の job の数字を受け取り、作業ディレクトリを root にした `gh api repos/{owner}/{repo}/actions/jobs/<job>` を REQ-180・REQ-182 の外部操作として REQ-412 の私的入口から同期で 1 回呼ぶ SHALL。結果は取得済みか取得不能かと、返った標準出力と標準エラーの合計バイト数とし、解析した値を検証せずに返す SHALL。環境変数 GH_REPO でリポジトリを切り替えず、宣言にない repo・run・job・ログを取得せず、job の情報の正否や提供元の完了を判定しない MUST。1 回の取得では監視による停止を REQ-412 の例外のまま投げ、取得不能や成功に置き換えない MUST。

Source: REQ-415

#### Scenario: 応答の取得
- **WHEN** gh が終了コード 0 で JSON を返す
- **THEN** 引数 `api` と `repos/{owner}/{repo}/actions/jobs/<job>` だけで root から gh を 1 回呼び、標準出力を既存の読み取りと同じく UTF-8 の文字列にして解析した値を取得済みとして返す。object 以外の値や id・run_id・status・conclusion・head_sha を検証しない

#### Scenario: 数字の桁
- **WHEN** job の数字が先頭の 0 を含む、安全な整数を超える、空である、または ASCII の 0〜9 以外の文字（改行を含む）を含む
- **THEN** 先頭の 0 だけを除いた 10 進の文字列（すべて 0 なら `0`）を API の path と結果に使い、桁を失わない。空か 0〜9 以外を含む入力は gh を起動する前に内部の誤用として拒否し、REQ-400 の CI 列が受け付ける数字は拒否しない

#### Scenario: 同じリポジトリ
- **WHEN** 環境変数 GH_REPO が別のリポジトリを指している
- **THEN** gh へ GH_REPO を渡さず、ほかの環境変数は既存の外部操作と同じく引き継ぐ。環境変数の値を結果と理由に含めない

#### Scenario: 取得不能
- **WHEN** gh がない、0 以外かシグナルで終わる、起動に失敗する、または標準出力を JSON として解析できない
- **THEN** 例外を投げずに取得不能とし、分類した理由とバイト数を返す。応答と標準エラーの本文を理由に含めない

#### Scenario: 1 回の出力の上限と監視の停止
- **WHEN** 標準出力と標準エラーの合計が 64MiB（呼出し側がより小さい上限を渡したときはその値）ちょうどか超える、native の受信が上限を超える、または 1 操作の期限・共有予算の使い切り・中断で止まる
- **THEN** 上限ちょうどまでは受け付ける。超過と native の受信の超過は出力の上限として、期限・共有予算・中断は REQ-412 のとおり実行時の失敗（ProcessLimitError）として投げ、期限までの出力は既存の例外の文字列に残す
