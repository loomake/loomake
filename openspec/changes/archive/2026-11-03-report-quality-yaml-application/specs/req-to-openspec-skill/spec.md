## ADDED Requirements

### Requirement: 品質 YAML の反映結果を報告する
Skill は、反映した UQ/PQ の ID と関連要件、まだ観測できない必須証拠と証拠不足になる対象、反映できず確認事項にした要件を報告に加えるよう定める SHALL。既存の報告四項目と次の一手は残す。

Source: REQ-411

#### Scenario: 反映と未反映・証拠不足を報告する
- **WHEN** Skill の報告手順を読む
- **THEN** 反映した ID と関連要件、未観測の必須証拠と証拠不足の対象、未反映で Q にした要件の三項目が番号付きである

#### Scenario: 既存の報告を保つ
- **WHEN** Skill の報告手順を読む
- **THEN** change 一覧・台帳集計・ブロッキング確認事項・未承認の仮定と次の一手が残り、既存の報告の試験も保たれる
