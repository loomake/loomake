## ADDED Requirements

### Requirement: 段階の境目ごとの Git の読み取り
`loomake run` は、エンジンを呼ぶ前、エンジンが終わった後、完了ゲートの検証の前、検証の後の各境目で、HEAD のコミットの SHA とブランチ名を 1 回の `git rev-parse` で読む SHALL。エンジンを呼ぶ前のこの呼び出しには、設定ファイルとフックのディレクトリの場所（REQ-198）も含める SHALL。git が実際に使う設定（REQ-204）は、エンジンの前と後で 1 回ずつ読む SHALL。各境目は自分で読み直し、ほかの境目で読んだ値を使わない SHALL。比べる値・止まる条件・表示・終了コードは REQ-126・REQ-198・REQ-204・REQ-205 のとおりとする SHALL。

Source: REQ-348

#### Scenario: エンジンの前後の読み取り
- **WHEN** エンジンがファイルを変えるだけで、HEAD・ブランチ・git の設定・フックを変えずに終える
- **THEN** エンジンを呼ぶ前の `git rev-parse` は 1 回、後の `git rev-parse` は 1 回、`git config --list` は前後で 1 回ずつで、run はそのタスクを完了にしてコミットする

#### Scenario: エンジンがコミットする
- **WHEN** エンジンが自分でコミットして終える
- **THEN** run はエンジンが終わったあとに読み直した HEAD で変化を見つけ、REQ-126 のとおり止まって終了コード 1 を返す

#### Scenario: 直しの前に読み直す
- **WHEN** 完了ゲートに不合格で、run が直しのためにエンジンを呼ぶ
- **THEN** 検証の後に読んだ HEAD を使わず、エンジンを呼ぶ直前に HEAD とブランチを読み直す

### Requirement: まとめた Git の読み取りの失敗
段階の境目のまとめた `git rev-parse` が、HEAD のコミットがないなどの通常の失敗に終わったときは、項目ごとの呼び出しに戻して、REQ-126・REQ-198 と同じ値を求める SHALL。期限・出力の上限・中断で止まったときは、項目ごとの呼び出しを起動せずに、REQ-180〜REQ-182 の失敗として扱う SHALL。

Source: REQ-348

#### Scenario: HEAD のコミットがない
- **WHEN** HEAD のコミットがないリポジトリで、エンジンの前の読み取りを行う
- **THEN** 項目ごとの呼び出しに戻り、SHA は空、ブランチ名は `HEAD` として、今までと同じ値を返す

#### Scenario: 読み取りが期限で止まる
- **WHEN** まとめた `git rev-parse` が 1 操作の期限に達する
- **THEN** 項目ごとの呼び出しを起動せず、時間の上限を示す実行時の失敗として止まる
