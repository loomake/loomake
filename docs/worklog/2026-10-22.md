- ブランチ add-init-cli を main から作り、仕様ゲートが合格することを確かめてから、tasks.md の 1.1〜3.1 を実装した。kit の本体と CLI はお互いに依存し、途中の版が動かないので、1.1〜1.8 は 1 つのコミットにした。テストと完了ゲートは別のコミットにしている。
- `@loomake/kit` に `runInit` を足し、`loomake init [--codex] [--devcontainer]` から呼ぶようにした。
  - AGENTS.md・CLAUDE.md・loomake.config.json・`.claude/skills/req-to-openspec/` を置く。`--codex` で `.agents/skills/` にも複製し（Q-09）、`--devcontainer` で `.devcontainer/devcontainer.json` を置く。
  - 同名で内容の異なるファイルは、unified diff を出してから「上書きしますか [y/N]」と聞く。既定は上書きしない（A-03）。改行コードだけの違いは同じ内容とみなす。確認を受け付けられない環境では、何も置かずに終了コード 1 で中止する（Q-06）。
  - package.json の `packageManager`、なければロックファイルで pnpm・npm・yarn を判定し、commands の既定値にする（A-01）。`tests.report` の既定値を書き、Vitest・Jest の設定例を表示する（A-05）。
  - `openspec/` が無ければ `openspec init` を案内する。
- 差分は、kit の実行時依存を core だけに保つ（REQ-047）ため自前で作った。
- devcontainer のテンプレートは、このリポジトリのものから、名前・volume・yomiyasu の更新・Codex を外した（A-04）。
- 確認を待つため、CLI の `main` を非同期にした。既存の CLI テストは結果を await するようにし、期待値は変えていない。
- tasks.md の 3.1 と trace.md の注記を `loomake verify` に合わせた。
