# #65 P3a verify の出力の秘密の置換

1. change `protect-verify-output` のタスク 1.1〜4.1 を実施した。REQ-451 として、runVerify の戻り値・進捗、失敗した品質コマンドと `openspec validate` の出力、`formatVerifyResult` の文字列、CLI のエラー表示（標準エラー）から、既知の形の秘密を `***` に置き換える。外部コマンドの出力は、全文を置換してから既存の上限（末尾 30 行・先頭 2000 文字）で切り、切った後も置換する。秘密鍵ブロックの BEGIN 行が切れて本文が残るのを防ぐためである。
2. 仕様ゲート（`--spec-only`）は exit 0。完了ゲート（`--done`）も exit 0（lint・型・テスト・要件ごとのテスト・quality すべて合格）。1 回目は時間切れ、2 回目はメモリ不足による lint の強制終了と時間依存の失敗で落ちた。落ちたテストは単独で通った。ゲートを 1 本ずつに戻した 3 回目で合格した。
3. 確認事項 Q-P3a-01・02・03・06 は ADR 0006 の包括承認に従い、おすすめで答えた（非ブロッキング）。新しい仮定はない。#65 の P3 は分けており、P3b（REQ-452 の trace record、REQ-453 と REQ-070 の report・旧 Evidence）は残る。親 #65 は閉じない。
4. 独立レビュー（Sonnet 5.5）の指摘を直した。内容は、切れ目をまたぐ置換のテスト、終了コード 3 の CLI テスト、`maskThenCut` への整理、未捕捉例外の経路の記録である。
5. 次は P3b を、parallel の #463・#69・#70 のマージ後に始める。
