# CLIリファレンス

生成元: `packages/cli/src/args.ts` の共通定義。生成ページを直接編集せず、定義を更新して再生成する。

再生成: `pnpm build && node scripts/generate-cli-reference.mjs`。照合: `node scripts/generate-cli-reference.mjs --check`。

## 共通操作と構文

| 操作 | 説明 | 適用条件 |
|---|---|---|
| -h, --help | 使い方を表示する | 先頭では全体、コマンド以降ではそのhelpを業務処理前に表示する |
| -v, --version | 版を表示する | 先頭引数として指定する。サブコマンドの固有オプションではない |

- 値付きオプションは --name value と --name=value を受け付ける。空値は拒否する。
- 空白区切りで次の値が -- から始まるときは値不足とする。等号区切りでは -- から始まる値も渡せる。
- 値付きオプションを反復すると最後の値を使う。flagの反復は1回と同じで、flagに等号で値を付けると拒否する。
- 知らないコマンド・オプション・位置引数は拒否する。近い候補があるときは日本語で示す。
- helpは同じ引数内のほかの処理より優先する。versionは先頭の引数としてだけ扱う。

## loomake init

使い方: loomake init &#91;--codex&#93; &#91;--devcontainer&#93;

AGENTS.md・CLAUDE.md・loomake.config.json・Skill をプロジェクトに置く。内容の違う同名のファイルは、確かめてから上書きする。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --codex | flag（値なし） | 任意 | false | 追加条件なし | Skill を .agents/skills/ にも置く（Codex 用） |
| --devcontainer | flag（値なし） | 任意 | false | 追加条件なし | .devcontainer/devcontainer.json を置く |

## loomake verify

使い方: loomake verify &#91;--change &lt;id&gt; (--spec-only &#124; --done)&#93; &#91;--json&#93; &#91;--skip-commands&#93;

仕様ゲートと完了ゲートで、仕様・確認事項・テストを検査する。--change を省くと、品質コマンドだけを実行する。終了コードは合格 0・不合格 1・使い方の誤り 2・実行時の失敗 3。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --change &lt;id&gt; | 値付き | 条件付き必須 | なし（省略時は品質コマンドのみ） | 英小文字・数字と、間に1つずつのハイフンで表すchange-id。--spec-onlyまたは--doneを指定するとき必須。指定時はどちらか片方のゲートが必要 | 検査する change |
| --spec-only | flag（値なし） | 条件付き必須 | false | --change指定時は--doneとのどちらか片方が必須。--changeなしでは指定不可 | 仕様ゲート：実装に入ってよいかを検査する |
| --done | flag（値なし） | 条件付き必須 | false | --change指定時は--spec-onlyとのどちらか片方が必須。--changeなしでは指定不可 | 完了ゲート：仕様ゲートに加え、タスク・要件ごとのテスト・品質コマンドを検査する |
| --json | flag（値なし） | 任意 | false | 追加条件なし | 結果を JSON で標準出力に出す（進捗は標準エラー） |
| --skip-commands | flag（値なし） | 任意 | false | 追加条件なし | 品質コマンドを実行せず、すでにあるテストのレポートを読む |

## loomake trace

使い方: loomake trace record --change &lt;id&gt;<br>       loomake trace report --change &lt;id&gt; &#91;--format md&#124;json&#93;<br>       loomake trace answer --change &lt;id&gt; --question &lt;Q-ID&gt; --answer &lt;回答&gt; --by &lt;回答者&gt; &#91;--date YYYY-MM-DD&#93;<br>       loomake trace approve --change &lt;id&gt; --assumption &lt;A-ID&gt; --by &lt;承認者&gt; &#91;--date YYYY-MM-DD&#93;

record・report・answer・approveの操作を指定する。

操作: record / report / answer / approve

## loomake trace record

使い方: loomake trace record --change &lt;id&gt;

verify --done を実行し、結果をコミットの SHA と合わせて .loomake/evidence/&lt;change-id&gt;/ に記録する。未コミットの変更があれば記録しない。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --change &lt;id&gt; | 値付き | 必須 | なし | 英小文字・数字と、間に1つずつのハイフンで表すchange-id | 記録する change |

## loomake trace report

使い方: loomake trace report --change &lt;id&gt; &#91;--format md&#124;json&#93;

いちばん新しい証拠の記録から、要件ごとのリリースレポートを標準出力に出す。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --change &lt;id&gt; | 値付き | 必須 | なし | 英小文字・数字と、間に1つずつのハイフンで表すchange-id | レポートを作る change（進行中になければ archive から探す） |
| --format md&#124;json | 値付き | 任意 | md | md / json | 出力の形式。省くと md |

## loomake trace answer

使い方: loomake trace answer --change &lt;id&gt; --question &lt;Q-ID&gt; --answer &lt;回答&gt; --by &lt;回答者&gt; &#91;--date YYYY-MM-DD&#93;

trace.md の確認事項へ回答を書く。すでに回答がある行は上書きしない。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --change &lt;id&gt; | 値付き | 必須 | なし | 英小文字・数字と、間に1つずつのハイフンで表すchange-id | 回答する change |
| --question &lt;Q-ID&gt; | 値付き | 必須 | なし | trace.mdの確認事項表に存在するID | 確認事項の ID |
| --answer &lt;回答&gt; | 値付き | 必須 | なし | 前後の空白を除いて空でない、改行を含まない文字列 | 確認事項への回答 |
| --by &lt;回答者&gt; | 値付き | 必須 | なし | 前後の空白を除いて空でない、改行を含まない文字列 | 回答を決めた人 |
| --date YYYY-MM-DD | 値付き | 任意 | 実行環境のローカル日付 | YYYY-MM-DDの実在する日 | 回答日。省くと今日の日付 |

## loomake trace approve

使い方: loomake trace approve --change &lt;id&gt; --assumption &lt;A-ID&gt; --by &lt;承認者&gt; &#91;--date YYYY-MM-DD&#93;

trace.md の仮定に承認を書く。すでに承認がある行は上書きしない。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --change &lt;id&gt; | 値付き | 必須 | なし | 英小文字・数字と、間に1つずつのハイフンで表すchange-id | 承認する change |
| --assumption &lt;A-ID&gt; | 値付き | 必須 | なし | trace.mdの仮定表に存在するID | 仮定の ID |
| --by &lt;承認者&gt; | 値付き | 必須 | なし | 前後の空白を除いて空でない、改行を含まない文字列 | 承認を決めた人 |
| --date YYYY-MM-DD | 値付き | 任意 | 実行環境のローカル日付 | YYYY-MM-DDの実在する日 | 承認日。省くと今日の日付 |

## loomake run

使い方: loomake run --change &lt;id&gt; &#91;--engine claude-code&#93; &#91;--dry-run&#93; &#91;--skip-permissions&#93;

change のタスクをエンジンに 1 つずつ実装させ、完了ゲートが通るまで直させて、PR を作る。

| オプション | 種類 | 必須性 | 省略時 | 受理値・条件 | 説明 |
|---|---|---|---|---|---|
| --change &lt;id&gt; | 値付き | 必須 | なし | 英小文字・数字と、間に1つずつのハイフンで表すchange-id | 実装する change |
| --engine &lt;名前&gt; | 値付き | 任意 | claude-code | claude-code | 使うエンジン。省くと claude-code（いまは claude-code だけ） |
| --dry-run | flag（値なし） | 任意 | false | 追加条件なし | エンジンに渡す予定のタスクと最初の指示を表示するだけで、実装しない |
| --skip-permissions | flag（値なし） | 任意 | false | LOOMAKE&#95;SANDBOX=1が必要 | 権限確認なしでエンジンを動かす。LOOMAKE&#95;SANDBOX=1 のときだけ使える |

## loomake doctor

使い方: loomake doctor

導入状態を調べ、足りない設定と直し方を表示する。ファイルは変えず、品質コマンドも実行しない。

固有オプションなし。
